# HALIANZA

**Open-source software for productivity, data analytics, and software development.**

HALIANZA is building a family of desktop applications designed to help people work, understand data, and create software with capable, accessible tools.

## Our projects

- **HALIANZA Office** — documents, spreadsheets, and presentations.
- **HALIANZA Data** — data analysis, dashboards, and business intelligence.
- **HALIANZA IDE** — a development environment focused on professional Java development.
- **HALIANZA Workspace** — notes, pages, tables, and kanban boards for organizing work.

These projects are in the planning and development stage. Features, platforms, and release dates will be documented in each project's repository as they become available.

## Open source

We intend to build in the open, document decisions, and welcome constructive feedback and community contributions as the projects mature. Licensing and contribution guidance will be published in the relevant repositories.

## Follow the work

Explore our repositories, follow development, report issues, and contribute when project guidelines are available.
